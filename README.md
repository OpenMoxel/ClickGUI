**#关于OpenClickGUI#**

**中文版本**

OpenClickGUI 是一个面向 Android 的开源 ClickGUI 项目，专注于提供简洁、现代且易于扩展的界面实现。项目旨在帮助开发者快速构建模块化 GUI，支持自定义布局、组件、主题与交互逻辑，并保持良好的代码可读性与可维护性。

OpenClickGUI 适合用于学习、二次开发以及个人开源项目。你可以自由修改界面样式、扩展组件功能，或将其集成到自己的 Android 项目中。

如果你觉得这个项目有帮助，欢迎 Star、Fork、提交 Issue 或参与贡献。

---

**English Version**

OpenClickGUI is an open-source ClickGUI project for Android, designed to provide a clean, modern, and easily extensible user interface implementation. It aims to help developers build modular GUIs quickly, with support for customizable layouts, components, themes, and interaction logic while keeping the code readable and maintainable.

OpenClickGUI is suitable for learning, modification, and personal open-source projects. You are free to customize the interface, extend its components, or integrate it into your own Android projects.

If you find this project useful, feel free to Star, Fork, open an Issue, or contribute to the project.

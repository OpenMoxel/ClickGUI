# HackAI

HackAI 是一个使用 Android 原生 Java 开发的 ClickGUI 界面展示项目，包含分类切换、模块开关、参数设置、中英文切换、通知、灵动岛和悬浮窗等交互效果。

本项目仅供开源学习、技术交流与非商业用途使用，禁止任何个人或组织倒卖本项目及其源码。
